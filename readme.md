# PATRACO.MX

## DESCRIPCIÓN

La página https://patracomexico.netlify.app/ es un sitio web enfocado al patronaje, trazo y corte textil. Se debe rediseñar la p{agina, utilizando un diseño moderno y responsivo.

### PARTES DE LA PÁGINA HOME

- Home
  - Logotipo de la empresa.
  - Link a página de Servicios
  - Link a sección de Como trabajmos
  - Link a página de Nosotros
  - Link a página de Contacto
  - Link directo a WhatsApp

- Sección Hero
  - Imagen hero de fondo
  - Titulo principal
  - Descripción general
  - Lista de servicios
    - patronaje profesional
    - graduación de tallas
    - trazo con menor consumo de tela
    - impresión de trazos
    - corte
    - confección (en algunos modelos)
  - link de solicitar cotización
  - link directo a WhatsApp
  - Contenedor div con logotipo del programa LECTRA y una descripción

### Herramientas que se utlizarán

Para lograr un sitio web totalmente responsivo, moderno y funcional, se implementarán HTML5, CSS3, JavaScript y el framework React, para la experiencia de usuario.
