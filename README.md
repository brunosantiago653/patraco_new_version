# PATRACO | Tecnología en Patronaje, Trazo y Corte Textil

> Landing page corporativa de alto rendimiento desarrollada para la empresa textil PATRACO, optimizada para máxima velocidad de carga, excelente posicionamiento SEO e integración directa de canales de atención (WhatsApp y Correo Electrónico).

##  Características Principales

- **Carga Ultra Rápida (Zero JS por defecto):** Arquitectura estática enfocada en rendimiento optimizado para dispositivos móviles y conexiones lentas.
- **Canales de Cotización Directos:** Enlaces integrados a WhatsApp API y correo electrónico corporativo (`mailto`).
- **Ubicación Interactiva:** Integración del mapa de Google Maps para fácil localización de la fábrica.
- **Diseño Responsivo:** Adaptabilidad fluida para pantallas móviles, tabletas y escritorio mediante CSS moderno.

---

##  Tecnologías Implmentadas

- **Framework Web:** [Astro](https://astro.build/) (Renderizado estático de alto rendimiento)
- **Frontend Core:** HTML5 semántico, CSS3 modular
- **Lógica de Cliente:** JavaScript Nativo (ES6+)
- **Control de Versiones:** Git & GitHub
